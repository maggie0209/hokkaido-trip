## 🚀 如何部署到 GitHub Pages（免費變成專屬網址＋手機離線 App）

### 方法一：直接用網頁上傳（最簡單，免打指令）

1. 登入 [GitHub](https://github.com/)，點擊右上角 **`+`** ➔ **`New repository`**。
2. **Repository name** 輸入例如：`hokkaido-trip`，選擇 **Public**，點擊 **`Create repository`**。
3. 點擊頁面上的 **`uploading an existing file`**。
4. 將本壓縮包解壓縮後的 5 個檔案（`index.html`、`manifest.json`、`sw.js`、`icon.svg`、`README.md`）全部拖曳進去，點擊下方綠色按鈕 **`Commit changes`**。
5. 點擊上方選單的 **`Settings`** ➔ 左側選單找到 **`Pages`**。
6. 在 **Build and deployment** 下的 **Branch**，將 `None` 改為 **`main`**（資料夾維持 `/ (root)`），點擊 **`Save`**。
7. 等待約 1～2 分鐘重新整理頁面，上方就會出現您的專屬網址：
   `https://<您的GitHub帳號>.github.io/hokkaido-trip/`

## 📱 如何加到手機主畫面（支援飛機上＆雪山無訊號 100% 離線使用）

本專案已內建 **PWA 離線快取（Service Worker）**，部署到 GitHub Pages 後：

- **iPhone (Safari)**：用 Safari 打開網址 ➔ 點擊底部中間的「**分享**」按鈕 ➔ 往下滑點選「**加入主畫面**」。
- **Android (Chrome)**：用 Chrome 打開網址 ➔ 點擊右上角「**⋮**」選單 ➔ 點選「**安裝應用程式**」或「**加到主畫面**」。

加到主畫面並開啟過一次後，就算在飛機上或山區沒有網路，也能隨時點開桌面上的小棕熊圖示查看行程、記帳與打勾待辦清單！
